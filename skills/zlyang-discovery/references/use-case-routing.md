# Purpose-driven research routes

The goal is not maximum sources. Select only sources that can change a downstream decision. Existing user context takes precedence; research should fill actual gaps.

| Purpose | Priority research sources | Distillation focus | Retrieval trigger | Do not misstate |
|---|---|---|---|---|
| Short-video content creation | original script/video, timestamped performance metrics where available, low-follower recent comparable posts, audience comments | topic, opening 5 seconds, emotional progression, spoken structure, mechanism, body-promise match, preserved original wording where authorized | hook / topic / emotional beat / script editing | high likes are not proof of causal mechanism; do not copy another creator's text verbatim |
| Marketing and lead generation | offer, customer interviews, funnel steps, objections, conversions | purchase reason, trust evidence, audience selection, CTA and measurable steps | qualified inquiry / conversion diagnosis | visibility is not sales evidence |
| Reusable knowledge lookup | primary documents, original examples, conflicting interpretations, updated sources | atomic concept, evidence, query phrases, applicability, counterexamples, related assets | question / decision situation / tags | an author's assertion is not verified fact |
| Executable SOP / Codex Skill | current versioned procedure, exceptions, failure logs, decisions, acceptance test | trigger, preconditions, branch, owners, output, rollback and tests | recurring task with matching constraints | newest or most common document is not automatically authoritative |
| Commercial decision | customers, actual offers and transactions, competitor products, costs, delivery evidence | hypotheses, constraints, evidence and smallest validation | investment / product / pricing decision | anecdotes and self-reported revenue are not verified profitability |

## Research sufficiency test
Proceed when there is enough evidence to create a correctly labeled, bounded artifact; otherwise name the evidence gap. Do not turn a limited analysis task into a mandatory lengthy market study. Separate performance targets from measured outcomes.

## Capture format
Each research finding records source_id, locator, date, observed/reported/inferred, relevance to declared purpose, open contradictions, and the future query phrases where it should be recalled.

## Content-creation example
For a user-supplied spoken script with specified hooks, emotional waves, originality boundaries and benchmark metrics: start with a structural extraction using the supplied script. Ask no more questions. If post metrics or original URL are absent, label causal/performance assessments as hypotheses and plan a separate optional benchmark study.
